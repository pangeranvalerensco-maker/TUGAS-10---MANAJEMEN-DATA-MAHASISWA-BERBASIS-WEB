# 🏆 Aplikasi Manajemen Data Mahasiswa Berbasis Web (CRUD)

Aplikasi ini adalah implementasi sederhana dari pengelolaan data mahasiswa yang menerapkan konsep **CRUD (Create, Read, Update, Delete)** menggunakan arsitektur **Java Spring Boot Layering (Controller–Service–Repository)**, database MySQL, dan Thymeleaf sebagai Template Engine.

## Fitur Utama Proyek

| Kategori | Fitur | Status |
| :--- | :--- | :--- |
| **Wajib** | CRUD Mahasiswa (Tambah, Lihat, Ubah, Hapus) | ✅ Implemented |
| **Arsitektur** | Implementasi Spring Boot Layering | ✅ Implemented |
| **Validasi** | Email Unik, Email Tidak Boleh Kosong, Format Email (@), Tahun Masuk Valid | ✅ Implemented |
| **Nilai Tambah** | Search (Nama), Filter (Jurusan), dan Pagination (5 data/halaman) | ✅ Implemented |
| **UI/UX** | Notifikasi Sukses/Gagal & Tampilan Stabil (CSS Murni) | ✅ Implemented |

---

## 🛠️ Teknologi yang Digunakan

* **Framework:** Java Spring Boot
* **Database:** MySQL
* **Template Engine:** Thymeleaf
* **Layer Data Access:** Spring Data JPA (Hibernate)
* **Bahasa:** Java
